# Дизайн «Банкнота» — спецификация для Flutter

Источник: холст Design (claude.ai). Макеты экранов лежат рядом в `screens/*.dc.html`.
Это HTML с inline-стилями: все размеры, отступы, радиусы и цвета берите оттуда как точные значения.
Синтаксис `{{...}}`, `<sc-for>`, `<sc-if>` — шаблонизатор редактора, читайте его как «цикл / условие / подстановку значения».

### Смысловые цвета (текст сумм)
- Доход: `#A8D98A` (тёмная) / `#3E7A2A` (светлая)
- Расход-акцент: `#FFA37E` / `#C2521F`; обычный расход — цвет основного текста
- Перевод: `#C3BBFF` / `#4A3AD6`
- Предупреждение (лимит ≥ 80%, Planned): `#F2C14E` / `#9A6B00`
- Перерасход / тревога: `#FF8E9D` / `#C53048`
- Цвет никогда не единственный сигнал: всегда есть знак «+ / −», процент или подпись.

### Градиенты
- Hero «Банкнота» (карточка капитала): `linear-gradient(140deg, #6A5AF9 0%, #4636D8 48%, #24195F 100%)`
  + гильош-узор: `repeating-radial-gradient(circle at 115% -20%, rgba(255,255,255,.07) 0 1px, transparent 1px 9px)`
  и `repeating-radial-gradient(circle at -20% 130%, rgba(133,187,101,.12) 0 1px, transparent 1px 11px)`.
  Тень: `0 24px 60px -24px rgba(106,90,249,.75)`.
- FAB «+»: `linear-gradient(140deg, #A6D987, #85BB65 45%, #4E9A3A)`, иконка `#0B0D12`.
- Основная кнопка: `linear-gradient(135deg, #8A7CFF, #6A5AF9 50%, #4636D8)`.
- Цель (золото): `linear-gradient(135deg, #FFE29A, #F2C14E 55%, #D99B2B)`.
- Линия графика: горизонтальный `#9C90FF → #85BB65`; заливка под линией: `#85BB65` от 35% до 0% сверху вниз.
- Фон экранов: базовый цвет + 1–2 мягких радиальных пятна (фиолетовое / зелёное, 14–30% альфы) в верхних углах.
- Прогресс: норма `#5E9C45 → #85BB65`, ≥80% `#E0A93A → #F2C14E`, >100% `#E2574C → #FF6B7F`.

Все числа — `FontFeature.tabularFigures()`. Формат: `12 480,35 Br`, `−9,99 $`, неразрывный пробел между разрядами, знак «−» (U+2212), валюта после суммы.

## Форма и отступы
- Сетка 4 pt; боковые поля экрана 20; между секциями 18–22; внутри карточек 14–18.
- Радиусы: hero 28 · крупные карточки 24–26 · карточки/строки 18–22 · кнопки 14–18 · плитки иконок 12–14 (42×42 → 14) · чипы 999.
- Карточки: заливка surface + бордер 1px outline, без тени (тень только у hero и FAB).
- Минимальная зона нажатия 44; основные кнопки 52–56; клавиши цифровой клавиатуры 52.
- Иконки: линейные, 24 viewBox, stroke 1.8–1.9, скругления концов. Без эмодзи.
- Planned-транзакция: бордер пунктиром `rgba(242,193,78,.55)`, подпись золотом.

## Анимации
| Что | Длительность / кривая | Детали |
|---|---|---|
| Появление блоков | 700ms, cubic(.2,.8,.2,1) | translateY 14 → 0 + fade, шаг между блоками 70–80ms |
| Прогресс-бары | 1100ms, cubic(.2,.8,.2,1), задержка ~500ms | scaleX от 0, слева |
| Столбцы аналитики | 900ms, тот же | scaleY от низа, шаг 80ms |
| Сегменты donut | 1000ms, cubic(.3,.7,.2,1) | по очереди, шаг 120ms |
| Отрисовка линии графика | 1800ms, cubic(.6,0,.2,1) | затем заливка fade 1.2s |
| Кольцо цели | 1600ms, cubic(.3,.7,.2,1) | |
| Тревожная точка | 2200ms ease-out, loop | расходящийся круг scale 1 → 3.2, fade |
| Блик на hero | 7s loop, активная фаза ~55% | светлая полоса под углом −18° |
| Свитч | 250ms, cubic(.3,1.4,.5,1) | лёгкий overshoot |
| Нажатие | 150ms | scale 0.96 |

Уважать `MediaQuery.disableAnimations`: при включённом — без анимаций.
